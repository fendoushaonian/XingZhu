# 星铸畅玩 

全套程序是用C++编写的，有C++基础的可以下载使用.

该全套程序是由 Michael 一个人独自开发的，仿照了Steam UI 编写，此套程序 里面的游戏下载 和 安装 已经完成了，然后 针对于 修改器类功能 等待开发，项目会持续更新.

目前也支持挂载Steam授权的游戏和号池的游戏合并，让用户实现能用星铸畅玩 游玩Steam游戏同时 游玩 号池的游戏 ，欢迎大家添加内容.

大家如果使用的话，记得带上作者，禁止私自虚假宣传 ，诈骗，可以用于商业.
